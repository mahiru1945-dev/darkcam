# 暗転カメラ

動画を撮りながら、画面は真っ黒にできる iPhone 用の Web アプリです。

**使う：** https://mahiru1945-dev.github.io/darkcam/ を iPhone の Safari で開いてください。

## 使い方
- 「カメラを起動」を押す
- 「暗転して撮影」で画面が真っ黒になり、撮影が始まる
  - 2回タップ：撮影を開始 / 停止
  - 長押し：元の画面に戻る
- 前のカメラ / 後ろのカメラの切り替え
- 撮った動画は一覧で見られる（すべて / 後ろのカメラ / 前のカメラ）
- 再生、「保存・共有」から写真アプリへの保存、削除

撮った動画は iPhone の中（このアプリの保存領域）だけに保存され、どこにも送信されません。

## 注意
- 画面ロックや他のアプリへの切り替えをすると撮影は止まります（そこまでは保存されます）
- 他人を無断で撮影・録音することは法律や条例に反する場合があります
